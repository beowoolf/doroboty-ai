# Prepared CV attachments

These one-page Polish PDFs belong to the synthetic Anna Kowalska and Marek Nowak personas. Employers, education and example.com contact addresses are fictional. Experience and outcomes extend the existing persona scenarios; each PDF includes a discreet teaching-data notice.

The files are static assets, with selectable text and embedded fonts. No generator, parser, service or additional participant setup is needed. The existing concise text representation remains stored in scenario data and application snapshots. Imported custom CV text is displayed as text instead of linking to an unrelated PDF.

Keep the versioned files immutable. A future CV revision must add a new versioned filename and explicit application snapshot handling; never replace the bytes of an existing attachment.
